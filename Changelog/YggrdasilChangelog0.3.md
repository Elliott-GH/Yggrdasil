# Yggdrasil App Changelog — Version 0.3.0

- **Version:** `0.3.0`
- **Date:** `2026-11-17`
- **Scope:** True Non-Web Native Desktop Software (`Yggdrasil.pyw`), Pro PDF Converter + Smart Linker & Gemini-Style `Version 3` Package

## Changed / Added
1. **Non-Web Native Desktop Application (`/04-yggdrasil-app/native_gui.py` & `YggdrasilDesktop.pyw`):**
   - Replaced the browser/HTTP dependency with a true console-less native Windows GUI built on `tkinter`, `ttk` (`clam` Nordic Aurora theme), and `tk.Canvas` (`pythonw.exe`).
   - Added 4 native workspace views behind a Gemini-inspired left navigation rail:
     1. `Studio & Tag Dispatch` (tag chips, presets, `Ctrl+Enter`, threaded execution, native `messagebox` `[/userinterface]` handoff dialog).
     2. `Pro PDF & Smart Linker` (inspired by `PDF converter.pyw`: `extract_numbers_from_filename`, `smart_sort_files`, LibreOffice detection, `pypdf.PdfWriter` batch merging, automatic `pdf_converter_function` + `smart_pdf_handling_function` cross-page BM25 & $W_i$ index generation, persistent JSON settings, `Ctrl+O`/`Ctrl+B`/`Ctrl+S`/`Ctrl+F`/`Ctrl+P`/`F5`/`Esc` shortcuts).
     3. `Live W_i Tree Canvas` (animated `tk.Canvas` Yggdrasil tree showing pulsing emerald air-gapped roots and cyan cloud-eligible leaves).
     4. `Changelogs & Vaults` (`ttk.Treeview` + native viewer over `Changelog/`, `markdowns_and_specs/`, `data_and_vaults/`, `user_content/`, and `resources/`).
2. **Gemini-Style Self-Sufficient `Version 3` Distribution (`/04-yggdrasil-app/dist_sync.py`):**
   - Packages `C:\AntiGravityFiles\output\Version 3\` with `Yggdrasil.pyw`, `YggdrasilAppLauncher.bat` / `.ps1`, `YGGDRASIL_BUILD_INFO.txt`, `version` (`0.3.0`), `app-0.3.0/`, `resources/`, `logs/`, `agents_and_lms/`, `data_and_vaults/`, `markdowns_and_specs/`, `user_content/`, and `Changelog/`.
   - Points `C:\AntiGravityFiles\output\Launch-Yggdrasil.bat`, `Launch-Yggdrasil.ps1`, and `C:\AntiGravityFiles\output\Yggdrasil.pyw` to `Version 3` while preserving `Version 1` and `Version 2`.

## Hotfix `0.3.1` — Launcher "won't run" fix (2026-11-17)
1. **`YggdrasilAppLauncher.bat` (generated by `dist_sync.py`):** `%PYW%` was set and expanded inside the same parenthesized `if (...)` block, so cmd expanded it as empty at parse time and `start` launched nothing. Rewritten with flat `if` lines + `goto :cli` / `:no_python` labels; shows a visible error and `pause` if no Python environment is found.
2. **`Version 3\Yggdrasil.pyw` (generated by `dist_sync.py`):** double-clicking used whatever `pythonw` Windows picked (system Python 3.14 without `pydantic`/`pypdf`), which crashed silently. The entrypoint now relaunches itself with the project venv (`.venv\Scripts\pythonw.exe`) on `ImportError`, and any fatal error is written to `logs\launch_error.log` and shown in a `messagebox` instead of failing silently.
